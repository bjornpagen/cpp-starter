This patch answers only an explicit __need_rsize_t request.
A normal inclusion of <stddef.h> does not declare rsize_t.
It still does not declare rsize_t when __STDC_WANT_LIB_EXT1__ is set.
Comment 5 described Clang's full-inclusion path.
This patch does not follow that path.
That path would put an Annex K name on targets whose C libraries lack Annex K.

The original rsize.cc test with Darwin -fmodules already compiles on trunk.
Current GCC does not report __has_feature(modules).
This patch adds the missing protocol.
It does not restore that old trigger.

This patch is for trunk only.
Do not ask for a GCC 16 backport.
